# رسالة فك بن نقاط التشغيل

موقع عربي ثابت مبني باستخدام HTML وCSS وJavaScript، دون قاعدة بيانات أو خادم.

## الملفات

- `index.html` — هيكل الصفحة.
- `style.css` — التصميم والألوان والحركات.
- `app.js` — التحقق من الأكواد وتدفق الواجهات والنسخ.
- `config.js` — **ملف الإعدادات المستقل** لتغيير الرسالة وإدارة قائمة الأكواد.
- `favicon.svg` — أيقونة الموقع.

## تغيير الأكواد والرسالة

افتح `config.js` وعدّل:

- `message`: الرسالة التي تظهر بعد التفعيل.
- `codes`: قائمة أكواد التفعيل. أضف أو احذف الأكواد داخل القائمة، مع الفصل بينها بفواصل.

احفظ التعديل ثم ارفع الملف إلى GitHub. عند استخدام GitHub Pages سيُنشر التحديث بعد اكتمال النشر.

## مهم: حدود خيار A

هذا المشروع لا يملك قاعدة بيانات أو تحققًا مركزيًا. لذلك:

1. تُحفظ الأكواد المستخدمة في `localStorage` داخل متصفح الزائر نفسه فقط.
2. يمكن استخدام الكود ذاته على جهاز أو متصفح آخر؛ فالموقع لا يعرف أن شخصًا آخر استخدمه.
3. مسح بيانات الموقع أو التخزين المحلي قد يسمح باستخدام الكود مرة أخرى على ذلك المتصفح.
4. قائمة الأكواد داخل `config.js` تُرسل إلى المتصفح ويمكن لأي زائر تقني الاطلاع عليها من ملفات الموقع.
5. لا توجد حماية موثوقة ضد التلاعب أو إعادة ضبط سجل الاستخدام.

**الخلاصة:** منع إعادة الاستخدام هنا محلي وتنظيمي فقط، وليس ضمانًا حقيقيًا لمرة واحدة على مستوى جميع الزوار. لا تستخدم هذا الأسلوب لأكواد تمنح قيمة مالية أو صلاحيات حساسة.

## النشر

يمكن نشر الملفات الثابتة عبر GitHub Pages من إعدادات المستودع: Settings → Pages، ثم اختيار الفرع `main` والمجلد `/(root)`.
