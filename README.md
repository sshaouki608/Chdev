# رسالة خاصة لك

موقع عربي ثابت يعمل باستخدام HTML وCSS وJavaScript فقط.

## الملفات
- `index.html`: شاشة الترحيب وصفحة الرسالة.
- `style.css`: التصميم المتجاوب.
- `app.js`: فتح الرسالة ونسخها.
- `config.js`: اسم الموقع والرسالة التي تظهر للزوار.

## تغيير الرسالة
عدّل قيمة `message` داخل `config.js` ثم احفظ التعديل في GitHub.

## طريقة الاستخدام
يفتح الزائر الموقع، يضغط «الدخول إلى الموقع»، فتظهر الرسالة مع زر «نسخ الرسالة».

لا يحتوي المشروع على حقول إدخال أكواد أو تحقق أو تفعيل أو قاعدة بيانات.
