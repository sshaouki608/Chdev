# رسالة فك بن نقاط التشغيل

موقع عربي ثابت بتصميم داكن وتقني، يعمل مباشرة دون قاعدة بيانات أو تسجيل دخول أو أكواد تفعيل.

## تجربة الزائر
1. تظهر واجهة الترحيب.
2. يضغط الزائر «الدخول إلى الموقع».
3. تظهر الرسالة المحددة.
4. ينسخ الرسالة بزر النسخ.

## تعديل الرسالة
عدّل قيمة `message` في `config.js`.

## الأداء
- لا توجد مكتبات JavaScript خارجية.
- لا توجد خطوط خارجية مطلوبة.
- ملفات محلية خفيفة مع رقم إصدار لتحديث ذاكرة التخزين المؤقت.
